# FP16 Tuning

+ A tool to fine-tune precision and performance of a engine, by trying to pull back the precision of layers from FP16 to FP32.

+ This tool is deprecated and useless since TensorRT-11 due to strongly-typed is forcely used.

+ Steps to run.

```bash
python3 main.py
```

+ Thanks Xuewei Li for providing the original design of this tool.
