# Integer

+ Two's complement, so a signed $n$ bit integer covers $[-2^{n-1}, 2^{n-1} - 1]$ and INT1 is $\{-1, 0\}$.

| Datatype | Maximum | Minimum |
| :------: | :-----: | :-----: |
| UINT64 | $18446744073709551615\approx1.845\times10^{19}$ | $0$ |
| INT64 | $9223372036854775807\approx9.223\times10^{18}$ | $-9223372036854775808\approx-9.223\times10^{18}$ |
| UINT32 | $4294967295\approx4.295\times10^{9}$ | $0$ |
| INT32 | $2147483647\approx2.147\times10^{9}$ | $-2147483648\approx-2.147\times10^{9}$ |
| UINT16 | $65535\approx6.553\times10^{4}$ | $0$ |
| INT16 | $32767\approx3.277\times10^{4}$ | $-32768\approx-3.277\times10^{4}$ |
| UINT8 | $255$ | $0$ |
| INT8 | $127$ | $-128$ |
| UINT4 | $15$ | $0$ |
| INT4 | $7$ | $-8$ |
| UINT2 | $3$ | $0$ |
| INT2 | $1$ | $-2$ |
| UINT1 | $1$ | $0$ |
| INT1 | $0$ | $-1$ |
